# Storage Backends

- [Memory](memory.md) — the default, in-process storage. Fast, not persistent across restarts.
- [Redis](redis.md) — persistent storage for distributed/high-traffic applications.
- [SQLite](sqlite.md) — persistent storage for single-instance applications.
- [TinyDB](tinydb.md) — lightweight, persistent document storage for small applications.
- [MongoDB](mongodb.md) — persistent storage for applications already using MongoDB.
- [PostgreSQL](postgresql.md) — persistent storage for applications already using PostgreSQL.
